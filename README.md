# 🛡️ Sandbox Launcher

A lightweight, user-friendly graphical front-end for Firejail, designed for Linux users who want to run untrusted applications safely. 

## Features
* Drag & Drop support
* Network and Home directory isolation
* Live Firejail log viewer
* Auto-updater

## Installation
Requires `python`, `tk`, `firejail`, and `tkinterdnd2`.
Run with: `python3 launcher.py`
